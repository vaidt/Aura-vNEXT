# docs/contract — the normative product contract

Specifications an implementation must satisfy, as distinct from `architecture/decisions/`
(which records *why* a decision was taken) and `docs/` generally (which explains how to
use the product).

| Document | Scope |
| --- | --- |
| [`M0-EVIDENCE-CONTRACT.md`](M0-EVIDENCE-CONTRACT.md) | The M0 canonical evidence domain, package format, and verifier contract |

A contract here is normative only where an ADR has accepted it. The ADR is the decision;
this is the statement of what was decided, in the form an implementer needs.
