# architecture/

Architecture records for Aura vNEXT.

| Path | Status | Contents |
| --- | --- | --- |
| [`decisions/`](decisions/) | NORMATIVE | Architecture decision records. The authority for architectural questions. |
| [`PRODUCT-DIRECTION.md`](PRODUCT-DIRECTION.md) | NON-NORMATIVE | Intended direction. Authorises nothing. |

An architecture question is answered by an ADR or it is open. It is not answered by code,
by a comment, by a prior agent's conclusion, or by this README.

Open architectural questions are tracked in
[`governance/OPEN-QUESTIONS.md`](../governance/OPEN-QUESTIONS.md).
